# CyberShield - Student Cyber Security Awareness
[![Project](https://img.shields.io/badge/Project-Cybersecurity-blue)](https://img.shields.io/badge/Project-Cybersecurity-blue) [![Status](https://img.shields.io/badge/Status-Completed-success)](https://img.shields.io/badge/Status-Completed-success) 

## About
CyberShield is a student-focused project aimed at educating students and regular internet users on common cyber threats and how to protect themself.
CyberShield provides an easy to understand guide to help educate students on how to protect themselves from phishing, passwords, malware, social engineering, online safety and incident reporting.

The main goal of this project is to encourage responsible usage of computers.
## Objectives
Educate users on common cyber threats
Explain cyber attacks on individuals and organisations
Encourage safe passwords and account management
Encourage responsible usage of the internet
Provide guidance on reporting cyber incidents
Increase awareness of methods to prevent cyber threats.

## Security Tips
Use strong passwords.
Enable Multi-Factor Authentication.
Keep devices up to date.
Don’t click any suspicious links.
Keep personal and confidential information safe.
Report any suspicious cyber activity.
